# Aseprite Batch Export

เครื่องมือ GUI บน Windows สำหรับ export sprite sheet จากไฟล์ `.aseprite` แบบ batch — เลือก layer และ tag ที่ต้องการ แล้วมันจะไล่ export **ทุกคู่ layer × tag** ให้ในคลิกเดียว

เหมาะกับงานที่ตัวละครหนึ่งตัวมีหลายสี (เก็บเป็น layer) และหลายท่าทาง (เก็บเป็น tag) เช่น 3 สี × 4 ท่า = 12 ไฟล์ ที่ปกติต้องนั่ง export ทีละอัน

---

## ต้องมีอะไรบ้าง

- **Windows** (ทดสอบบน Windows 11) — ใช้ PowerShell 5.1 กับ .NET Framework ที่ติดมากับเครื่องอยู่แล้ว ไม่ต้องลงอะไรเพิ่ม
- **Aseprite** ฉบับที่มี CLI (ตัวที่ซื้อจาก Steam / itch.io / เว็บทางการ ใช้ได้หมด) — ต้องรู้ path ของ `Aseprite.exe`

> path ที่พบบ่อย
> `C:\Program Files\Aseprite\Aseprite.exe`
> `C:\Program Files (x86)\Steam\steamapps\common\Aseprite\Aseprite.exe`
>
> ถ้าลง Steam ไว้คนละไดรฟ์ ให้ดูใน `SteamLibrary\steamapps\common\Aseprite\`

---

## วิธีใช้

1. ดับเบิลคลิก **`Aseprite Batch Export.bat`**
2. ช่อง **Aseprite** — ปกติโปรแกรมจะ **หา `Aseprite.exe` ให้เองตั้งแต่เปิด** (ดูตามที่ติดตั้งทั่วไปและ Steam library ทุกไดรฟ์) ถ้าหาไม่เจอให้กด `Browse...` เลือกเอง หรือกด **ค้นหาให้** เพื่อลองใหม่
3. ช่อง **ไฟล์งาน** → กด `Browse...` เลือกไฟล์ **หรือลากไฟล์ `.aseprite` มาวางบนหน้าต่างได้เลย**
   โปรแกรมจะ **สแกนไฟล์อัตโนมัติ** แล้วเอา layer/tag ที่มีอยู่จริงมาขึ้นเป็นรายการให้ติ๊ก
   (ถ้าแก้ path ด้วยการพิมพ์เอง ให้กดปุ่ม **สแกนใหม่** เอง)
4. ติ๊กเลือก **Layers** และ **Tags** ที่ต้องการ — ดูชื่อไฟล์ที่จะได้ในแท็บ **พรีวิวชื่อไฟล์** และดูการเรียงเฟรมในแท็บ **Sheet type** ด้านล่าง
   หัวกรอบจะบอกจำนวนที่เลือกไว้ เช่น `Layers — เลือก 2 / 5`
5. ตั้ง **รูปแบบชื่อไฟล์** (ดูหัวข้อ [ชื่อไฟล์ผลลัพธ์](#ชื่อไฟล์ผลลัพธ์)) กับ **โฟลเดอร์ปลายทาง** (เว้นว่างไว้ = ใช้โฟลเดอร์ของไฟล์ `.aseprite`)
6. กด **Export** — ดูความคืบหน้าจากแถบด้านล่าง และรายละเอียดในแท็บ **Log** ระหว่างทางกด **ยกเลิก** ได้ (จะหยุดหลังไฟล์ที่กำลังทำอยู่เสร็จ)

> ปุ่ม Export จะกดไม่ได้จนกว่าจะติ๊ก Layers และ Tags อย่างน้อยอย่างละ 1 รายการ
> เส้นคั่นระหว่างลิสต์กับพรีวิวลากปรับสัดส่วนได้

ค่าที่ตั้งไว้จะถูกบันทึกตอนกด Export และโหลดกลับให้อัตโนมัติในครั้งถัดไป (รวมถึงติ๊ก layer/tag เดิมให้ด้วย)

## ชื่อไฟล์ผลลัพธ์

ตั้งเองได้ในช่อง **รูปแบบชื่อไฟล์** โดยใส่ตัวแปรตรงไหนก็ได้ (ตัวพิมพ์เล็ก-ใหญ่ไม่มีผล, `{Layer}` / `{Tag}` ก็ใช้ได้):

| ตัวแปร | แทนด้วย |
| --- | --- |
| `{Layers}` | ชื่อ layer |
| `{Tags}` | ชื่อ tag (ช่องว่างถูกแทนด้วย `_`) |
| `{File}` | ชื่อไฟล์ `.aseprite` (ไม่มีนามสกุล) |

ปุ่ม **+ {Layers}** / **+ {Tags}** จะแทรกตัวแปรตรงตำแหน่งเคอร์เซอร์ `.png` ต่อท้ายให้เอง ถ้าเว้นช่องว่างไว้จะใช้ค่าตั้งต้น `{File}_{Layers}_{Tags}`

ตัวอย่าง รูปแบบ `SPA_VFX_GangsterMonkey__BananaBigBullet_{Layers}_{Tags}`, layer `Explosion`, tag `Attack Down`:

```
SPA_VFX_GangsterMonkey__BananaBigBullet_Explosion_Attack_Down.png
```

ถ้าไม่ใส่ `{Layers}` หรือ `{Tags}` แล้วติ๊กไว้หลายรายการ ชื่อไฟล์จะซ้ำกัน — พรีวิวจะขึ้นเตือน `ชื่อซ้ำ!` ให้เห็น
อักขระที่ใช้ในชื่อไฟล์ไม่ได้ (`\ / : * ? " < > |`) จะถูกแทนด้วย `_`
settings รุ่นเก่าที่เก็บ `Prefix` ไว้ จะถูกแปลงเป็น `<prefix>_{Layers}_{Tags}` ให้อัตโนมัติ

แท็บ **พรีวิวชื่อไฟล์** จะแสดงรายชื่อทั้งหมดแบบสด ๆ (ดับเบิลคลิกที่รายการเพื่อเปิดไฟล์ ถ้ามีอยู่แล้ว) พร้อมคำเตือน 2 แบบ:

| คำเตือน | หมายถึง |
| --- | --- |
| `<< มีไฟล์เดิม จะถูกเขียนทับ` | ในโฟลเดอร์ปลายทางมีไฟล์ชื่อนี้อยู่แล้ว |
| `<< ชื่อซ้ำ! จะทับกันเอง` | มีสองคู่ layer/tag ที่ให้ชื่อไฟล์เดียวกัน เช่น tag `Attack Down` กับ `Attack_Down` |

## Sheet type

แท็บ **Sheet type** แสดงผังเปรียบเทียบทั้ง 5 แบบว่าเฟรมจะถูกเรียงยังไง (ตัวเลขคือลำดับเฟรม) กดที่ผังไหนก็เลือกแบบนั้นได้เลย

| แบบ | การเรียง |
| --- | --- |
| `horizontal` | เรียงเป็นแถวเดียวในแนวนอน |
| `vertical` | เรียงเป็นคอลัมน์เดียวในแนวตั้ง |
| `rows` | ตารางประมาณสี่เหลี่ยมจัตุรัส ไล่ **ซ้ายไปขวา** ทีละแถว |
| `columns` | ตารางเหมือนกัน แต่ไล่ **บนลงล่าง** ทีละคอลัมน์ |
| `packed` | จัดเรียงให้ชิดกันที่สุด เฟรมขนาดต่างกันได้ ไม่เป็นตาราง |

ปุ่ม **เรนเดอร์ตัวอย่างจริง** จะสั่งให้ Aseprite export คู่ layer/tag แรกที่ติ๊กไว้ออกมาจริง ๆ แล้วแสดงภาพนั้นพร้อมขนาดเป็นพิกเซล (พื้นหลังลายหมากรุก = ส่วนที่โปร่งใส) ภาพจะถูกขยายเป็นจำนวนเต็มเท่าเพื่อให้พิกเซลอาร์ตยังคม และไม่เขียนไฟล์ลงโฟลเดอร์ปลายทาง — ใช้ไฟล์ชั่วคราวแล้วลบทิ้ง

## ปุ่มและตัวเลือก

| ส่วน | ทำอะไร |
| --- | --- |
| **ค้นหาให้** | ค้นหา `Aseprite.exe` อัตโนมัติ (Program Files, itch, Steam library ทุกไดรฟ์) |
| **สแกนใหม่** | ดึงรายชื่อ layer และ tag จากไฟล์ `.aseprite` มาขึ้นลิสต์ (ติ๊กที่เลือกไว้เดิมจะถูกติ๊กคืนให้) |
| **ทั้งหมด / ล้าง** | ติ๊ก/ยกเลิกทั้งลิสต์ |
| **+ เพิ่มเอง** | พิมพ์ชื่อ layer/tag เพิ่มเข้าลิสต์เอง เผื่อกรณีสแกนไม่ได้ผล |
| **Sheet type** | รูปแบบการจัดเรียงเฟรม เลือกจากผังในแท็บ Sheet type ก็ได้ |
| **เรนเดอร์ตัวอย่างจริง** | ให้ Aseprite เรนเดอร์คู่แรกที่ติ๊กไว้ออกมาดูของจริงตาม sheet type ปัจจุบัน |
| **ข้ามเฟรมว่าง** | ข้ามเฟรมที่ว่างเปล่า (ส่ง `--ignore-empty` ให้ Aseprite) |
| **รูปแบบชื่อไฟล์** | ตั้งชื่อไฟล์เอง ใส่ `{Layers}` `{Tags}` `{File}` ได้ — เว้นว่าง = `{File}_{Layers}_{Tags}` |
| **+ {Layers} / + {Tags}** | แทรกตัวแปรลงช่องรูปแบบชื่อไฟล์ตรงเคอร์เซอร์ |
| **เปิดโฟลเดอร์** | เปิดโฟลเดอร์ปลายทางใน Explorer |
| **ยกเลิก** | หยุด export กลางคัน (ไฟล์ที่กำลังทำอยู่จะทำให้จบก่อน) |

## เบื้องหลังทำงานยังไง

ทั้งหมดเรียก Aseprite CLI ในโหมด batch (`-b`) ไม่เปิดหน้าต่างโปรแกรม

**ตอนสแกน**

```
Aseprite.exe -b --list-layers <file.aseprite>
Aseprite.exe -b --list-tags   <file.aseprite>
```

**ตอน export** (ยิงหนึ่งครั้งต่อหนึ่งคู่ layer × tag)

```
Aseprite.exe -b --layer <layer> --frame-tag <tag> <file.aseprite> [--ignore-empty] --sheet-type <type> --sheet <output.png>
```

ก่อน export แต่ละไฟล์ โปรแกรมจะลบไฟล์ปลายทางเดิมทิ้งก่อน เพื่อให้สถานะ `OK` ในหน้า Log แปลว่า "สร้างไฟล์สำเร็จจริงในรอบนี้" ไม่ใช่แค่เจอไฟล์เก่าค้างอยู่

## แก้ปัญหา

**กด Scan แล้วลิสต์ว่างเปล่า**
ดูข้อความจาก Aseprite ในแท็บ Log ประกอบ — อาจเป็นเวอร์ชันเก่าที่ยังไม่มี `--list-layers` / `--list-tags` หรือไฟล์นั้นไม่มี tag เลย ระหว่างนี้ใช้ปุ่ม **+ เพิ่มเอง** พิมพ์ชื่อเองไปก่อนได้

**Log ขึ้น `WARNING: ไม่พบไฟล์ผลลัพธ์`**
Aseprite รันจบแต่ไม่ได้เขียนไฟล์ออกมา สาเหตุที่พบบ่อยคือชื่อ layer/tag ไม่ตรงเป๊ะ (ตัวพิมพ์เล็ก-ใหญ่ต่างกัน) หรือ tag นั้นไม่มีเฟรมใน layer นั้นจริง ๆ — ดู exit code กับข้อความที่ต่อท้ายในบรรทัดเดียวกัน

**เปิดแล้วไม่มีอะไรขึ้น**
ลองรัน `AsepriteExportGUI.ps1` จากหน้าต่าง PowerShell ตรง ๆ เพื่อดู error:

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File ".\AsepriteExportGUI.ps1"
```

**แก้โค้ดแล้วภาษาไทยกลายเป็นตัวประหลาด**
`AsepriteExportGUI.ps1` ต้องบันทึกเป็น **UTF-8 with BOM** เท่านั้น — PowerShell 5.1 อ่านไฟล์ UTF-8 ที่ไม่มี BOM เป็น ANSI ทำให้ข้อความไทยเพี้ยนทั้งไฟล์

## ข้อจำกัดที่รู้อยู่

- ทำได้ทีละไฟล์ `.aseprite` (batch ในที่นี้หมายถึงหลาย layer × tag ไม่ใช่หลายไฟล์)
- ไฟล์ settings เก็บรายการที่เลือกเป็นข้อความคั่นจุลภาค ถ้าชื่อ layer/tag มีเครื่องหมาย `,` อยู่ในตัว การติ๊กคืนอัตโนมัติจะไม่ตรง (ตัว export เองไม่มีปัญหา)
- ระหว่าง export โปรแกรมรัน Aseprite ทีละคู่แบบรอให้จบ หน้าต่างจึงอาจหน่วงเป็นช่วง ๆ (กด **ยกเลิก** ได้ ระบบจะหยุดหลังไฟล์ที่กำลังทำอยู่เสร็จ)
